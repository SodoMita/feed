# 🎮 Game Design Document — «FEED»
*Версия 1.0*

---

## 1. Концепция

**Название:** FEED
**Жанр:** Нарративная карточная игра (Reigns-like)
**Платформа:** Web (мобильная адаптация)
**Целевая аудитория:** 16–35 лет, пользователи соцсетей, люди с опытом создания контента или его потребления
**Длина одной сессии:** 10–25 минут
**Количество концовок:** 5
**Количество карточек:** ~60 уникальных + ~30 вариативных

### Ценностное предложение
Игра исследует, кем становится человек (и его онлайн-персона) под давлением алгоритмов, денег, аудитории и собственных желаний. Это критика культуры инфлюенсеров, сделанная изнутри — без морализаторства.

---

## 2. Механики

### 2.1 Базовая механика карточек
- Игроку показывается карточка с текстом и персонажем
- Два варианта выбора: свайп влево или вправо (или кнопки)
- Каждый выбор изменяет одну или несколько метрик
- Выбор влияет на флаги, которые открывают/закрывают карточки и концовки

### 2.2 Метрики
Четыре ресурса, каждый от 0 до 10:

| Метрика | Иконка | Обнуление = | Максимум = |
|---|---|---|---|
| Охват (Reach) | 📡 | Бан / теневой бан | Эксплуатация алгоритмом |
| Душа (Soul) | 🫀 | Ты становишься ботом | Слишком уязвим |
| Монета (Money) | 💰 | Аккаунт продают | Ты продал всё |
| Топливо (Energy) | ⚡ | Выгорание | Гиперактивность |

**Визуализация:** горизонтальные полоски под карточкой, цвет меняется с зелёного на красный при экстремумах.

**Смерть аккаунта** наступает, если любая метрика достигает 0 или 10 — показывается экран «смерти» с объяснением, что произошло, и предложением начать заново.

### 2.3 Флаги (состояния)
Булевые флаги, которые меняют доступные карточки:

| Флаг | Как активируется | Эффект |
|---|---|---|
| `sasha_trust` | Несколько добрых ответов Саше | Открывает финальные реплики Саши |
| `mirror_absorbed` | Поглощение @Mirror | Буст метрик, но Саша замечает |
| `hater_transformed` | Три взаимодействия с хейтером | Хейтер → союзник |
| `alina_story` | Трижды отказать Алине | Алина открывается |
| `viral_union` | Принять союз с ViralKing | Блокирует «Тишину» и «Документ» |
| `pavlov_interview` | Принять интервью Павла | Открывает «Документ» |
| `algorithm_spoken` | Высокая Душа + честный путь | Алгоритм говорит человечески |

### 2.4 Перки (Perks)
Постоянные бонусы или штрафы, получаемые за определённые паттерны выбора:

**Позитивные:**
- 🌟 **«Аутентичный»** — 3 раза подряд выбрал «честный» вариант → Душа не падает ниже 2
- 🤝 **«Нетворкер»** — принял 3+ коллаба → Охват бонус +1 к каждому будущему коллабу
- 📚 **«Осведомлённый»** — дал интервью Павлу → скрытая информация в карточках
- ⚡ **«Машина»** — 5 постов подряд без паузы → Топливо регенерирует быстрее

**Негативные:**
- 🤖 **«Алго-раб»** — 4 раза адаптировался под алгоритм → каждое изменение Алгоритма снижает Душу на -1 автоматически
- 💸 **«Продажный»** — 3+ рекламных интеграции подряд → Саша начинает молчать
- 😤 **«Скандалист»** — 2+ публичных конфликта → хейтеры появляются чаще
- 🫥 **«Невидимка»** — низкий охват 5 карточек подряд → Алгоритм теневой банит

### 2.5 Прогресс сюжета (Stages)
Три этапа определяются количеством «постов» (пройденных карточек):
- **Этап 1:** карточки 1–15
- **Этап 2:** карточки 16–35
- **Этап 3:** карточки 36–55
- **Концовка:** карточка 56+

В конце каждого этапа — обязательная «сюжетная» карточка, которую нельзя пропустить.

### 2.6 Колода карточек
Карточки делятся на типы:
- **Сюжетные** — обязательные, в фиксированном порядке
- **Персонажные** — привязаны к персонажу, появляются по флагам
- **Событийные** — случайные (из пула), появляются при определённых значениях метрик
- **Алгоритмические** — появляются при экстремальных значениях метрик

## 3. Арт-стиль

### 3.1 Визуальный язык
- **Карточки:** тёмный фон (#0d0d0d), текст белый/серый
- **Персонажи:** большие одиночные эмодзи (64–96px) + имя
- **Метрики:** тонкие горизонтальные полоски, цвет по состоянию
- **Анимации:** мягкие свайпы, лёгкие частицы при изменении метрик
- **Фон:** абстрактный медленный noise-эффект, как «помехи» в ленте

### 3.2 Эмодзи как полноценная графика
Каждый персонаж — эмодзи-аватар. Эмодзи используются:
- как аватарки персонажей
- как иконки метрик
- как «реакции» в карточках
- как элементы декора текста

### 3.3 Векторные элементы
- Логотип FEED (простой, леттеринг)
- Иконки метрик (SVG)
- Фоновые абстрактные линии (имитация UI соцсети)
- Анимированные частицы при получении перка

## 4. Звук

### 4.1 Процедурный звук
Все звуки генерируются через Web Audio API:

| Событие | Звук |
|---|---|
| Свайп влево | Короткий нисходящий тон (sine wave) |
| Свайп вправо | Короткий восходящий тон |
| Метрика растёт | Мягкий позитивный пинг |
| Метрика падает | Тихий негативный шум |
| Смерть аккаунта | Длинный затухающий тон |
| Новый персонаж | Краткий аккорд появления |
| Получение перка | Трезвучие |
| Финал/концовка | Медленная генеративная мелодия |

### 4.2 Фоновая атмосфера
Тихий генеративный ambient: случайные очень тихие пинги (имитация уведомлений), низкочастотный гул (имитация работающей системы). Не навязчиво — скорее ощущается, чем слышится.

## 5. UX / Интерфейс

### 5.1 Экраны
1. **Стартовый экран** — название, кнопка начать, краткое описание
2. **Основной экран игры** — карточка + метрики
3. **Экран смерти** — объяснение + кнопки «начать заново» / «посмотреть концовки»
4. **Экран концовки** — финальный текст + ачивка
5. **Журнал** — список пройденных персонажей и их комментарии

### 5.2 Карточка (основной элемент)
```
┌─────────────────────────────┐
│  [эмодзи персонажа]         │
│  Имя персонажа              │
│                             │
│  «Текст карточки...»        │
│                             │
│  ← [текст выбора 1]         │
│     [текст выбора 2] →      │
└─────────────────────────────┘
[📡 ████░░░░░░] [🫀 ██████░░░░]
[💰 ███░░░░░░░] [⚡ ████████░░]
```

### 5.3 Предпросмотр эффекта
При наведении/удержании на вариант выбора — слабая анимация полосок показывает, что изменится. Не точные числа — только направление.

---

## 6. Нарративные правила

1. **Без правильного ответа** — каждый выбор имеет последствия, нет «правильного» пути
2. **Персонажи помнят** — флаги обеспечивают преемственность реплик
3. **Ирония без морализаторства** — игра не говорит тебе, что хорошо. Она показывает последствия.
4. **Реплики персонажей в 1–3 предложения** — Reigns-стиль: кратко и сильно
5. **Финальные тексты длиннее** — концовки — единственное место для развёрнутого текста

## 7. Журнал персонажей (мета-слой)

После первого прохождения открывается «Журнал» — коллекция встреченных персонажей. Каждый персонаж — это:
- Его аватарка (эмодзи)
- Имя
- Краткая характеристика
- **3–5 его «закулисных» комментариев** — персонаж рефлексирует о происходящем, иногда ломает четвёртую стену

Это и есть «агенты, комментирующие всякое» — они живут в журнале и говорят о игре изнутри.

### Примеры закулисных комментариев:

**🌱 Саша:**
*«Я помню, как ты начинал. До первого поста. Было хорошее время»*
*«Иногда я думаю — если бы я не написал тебе первым, кем бы ты стал?»*
*«Ты можешь начать заново. Я подпишусь первым снова. Обещаю»*

**🤖 А. (Алгоритм):**
*«Вовлечённость этого прохождения: 73%. Ниже среднего. Это хороший знак»*
*«Ты нажал «честный» вариант 12 раз. Это нерационально. Это интересно»*
*«[СИСТЕМНОЕ СООБЩЕНИЕ]: что такое смысл? запрос не распознан»*

**💼 Алина:**
*«Не думай, что я злодей. Я просто реалист. Хотя иногда я в этом не уверена»*
*«Ты отказался от моей сделки в третий раз. Это было правильно. Не говори никому, что я это сказала»*
*«Мой аккаунт назывался @AlinaKreative. Там было 47 постов. Все честные. Никто не видел»*

**😤 Хейтер:**
*«Я не хотел тебе навредить. Я просто не знал другого способа участвовать»*
*«Если дашь мне шанс — я могу быть нормальным. Сложно, но могу»*
*«...спасибо, что не заблокировал сразу»*

**📰 Павел:**
*«Всё, что происходит в игре — реальные паттерны. Я видел их сотни раз»*
*«Самая честная концовка — «Тишина». Но никто не верит, что это возможно»*
*«Ты — хороший материал. Это комплимент. Почти»*

**🔥 ViralKing:**
*«Я не прошу тебя стать плохим. Я прошу тебя стать большим. Разница есть. Наверное»*
*«Иногда ночью я смотрю на метрики и думаю — это всё? Да. Но «всё» — это много»*
*«Если ты выбрал «Тишину» — я понимаю. Не говори мне где ты теперь»*

**🪞 @Mirror:**
*«Ты прошёл дальше меня. Я горжусь. Или завидую. Или это одно и то же»*
*«Мы оба знаем, чем это кончится. Вопрос только — как»*
*«До свидания, @YOU. До следующего раза»*

## 8. Технический стек

- **Frontend:** React + TypeScript
- **Стили:** Tailwind CSS
- **Анимации:** CSS transitions + Framer Motion (или чистый CSS)
- **Звук:** Web Audio API (процедурный)
- **Хранение состояния:** React useState / useReducer
- **Сборка:** Vite

---

## 9. Метрики успеха (дизайн-цели)

- Игрок должен хотеть перепройти игру хотя бы раз
- Каждая концовка должна ощущаться заработанной, а не случайной
- Хотя бы одна карточка должна вызвать «ой, это про меня»
- Журнал персонажей должен читаться как самостоятельное произведение
