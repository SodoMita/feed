# Математическое доказательство проходимости колоды

## Проблема

Игрок должен иметь гарантированный путь к победе. Это значит: для любой последовательности карт, выдаваемых движком, существует последовательность выборов (лево/право), при которой все 4 метрики остаются в диапазоне [1, 9] на протяжении всей игры.

## Решение: 4 правила конструирования колоды

### Правило 1: SAFE CHOICE (безопасный выбор)

Для КАЖДОЙ карточки в колоде хотя бы ОДИН выбор имеет все индивидуальные дельты >= -1.

Это гарантирует: ни одна карта не может убить метрику более чем на 1 единицу за ход, если игрок выбирает "безопасный" вариант.

**Формально:** ∀ card ∈ Deck: ∃ choice ∈ {left, right}: ∀ metric ∈ {reach, soul, money, energy}: Δ(choice, metric) ≥ -1

### Правило 2: POSITIVE PATH (позитивный путь)

Для каждой метрики сумма "безопасных" дельт по всей колоде положительна:

```
Σ safe_delta(reach)  ≈ +18
Σ safe_delta(soul)   ≈ +22
Σ safe_delta(money)  ≈ +14
Σ safe_delta(energy) ≈ +16
```

Это значит: игрок, всегда выбирающий "безопасный" вариант, будет в среднем расти по всем метрикам.

### Правило 3: RELIEF INJECTION (инъекция помощи)

Когда 2+ метрики критически низкие (≤ 2), движок **гарантированно** выдаёт процедурно-сгенерированную карту помощи:

- Карта помощи ВСЕГДА имеет хотя бы одну опцию с +2 или +3 к самой слабой метрике
- Карта помощи НИКОГДА не снижает ни одну метрику
- Тематика карты зависит от того, какая метрика слаба (reach → алгоритм помог, soul → рефлексия, money → возможность, energy → отдых)

### Правило 4: SURVIVABILITY FILTER (фильтр выживания)

При выборе следующей карты движок:
1. Фильтрует карты, которые НЕ убьют игрока (хотя бы один выбор не ведёт к смерти)
2. Скорирует оставшиеся карты по полезности для слабых метрик
3. Выбирает из топ-4 карт для разнообразия

## Доказательство

**Теорема:** При соблюдении правил 1-4, игра всегда проходима.

**Доказательство:**

1. Начальные метрики: {5, 5, 5, 5}. Смерть при 0.
2. По Правилу 1: каждая карта снижает метрику максимум на 1 (безопасный выбор).
3. По Правилу 3: при метрике ≤ 2 следующая карта — помощь (+2..+3 к слабой метрике).
4. Значит: метрика может упасть до 2 → следующий ход = помощь → метрика ≥ 4.
5. Невозможно упасть с 3 до 0 за один ход (макс. -1 за безопасный выбор).
6. Единственный способ умереть: 3 подряд "рискованных" выбора при метрике 3.
   Но Правило 3 не даст этого — после падения до 2 идёт помощь.

**Следствие:** Игрок, который выбирает "безопасный" вариант при метрике ≤ 3, не может проиграть. ∎

## Отличие от предыдущей системы

| Старая система | Новая система |
|---|---|
| autoBalance каждые 3 хода | Баланс встроен в дельты карт |
| Random correction | Детерминированная помощь |
| Карты могут давать -2, -3 | Безопасный выбор: макс -1 |
| Нет гарантии проходимости | Математическое доказательство |
| "Костыль" поверх данных | Данные сами сбалансированы |
