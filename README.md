# 📱 FEED — Игра про инфлюенсера

> *Reigns-like игра про путь создателя контента в социальных сетях*

## 🎮 О игре

Лента помнит всех. Тебя она ещё не знает — ты новый аккаунт: серый круг на аватарке,
пустая биография. Впереди — вся лента.

Каждая карточка — решение: чей голос услышать, кому отдать время, что считать своим.
Решения меняют тебя — охват, душу, деньги, силы. Лента не прощает нуля. И не прощает всего.

## 📊 Метрики

- **📡 Охват** — тебя видят
- **🫀 Душа** — ты настоящий
- **💰 Монета** — ты в деньгах
- **⚡ Топливо** — у тебя силы

Держи баланс. Или выбери путь.

## ✨ Особенности

### Глубокая механика
- **100+ уникальных карточек** с разными персонажами
- **3 этапа развития**: Старт → Рост → Вершина
- **13 перков** (позитивных и негативных)
- **Флаги и триггеры** для ветвления сюжета
- **Числа на карточках всегда равны результату** — текст и метрики не расходятся
- **Карточки-предложения**: каждая карта — предложение персонажа; свайп вправо (зелёный ✓) = согласиться, влево (красный ✕) = отказаться

### Разные концовки

- **📡 Вечная лента** — стать везде
- **🌿 Тишина** — уйти с миром
- **🌱 Новый старт** — начать заново
- **🔮 Слияние** — создать платформу
- **📖 Документ** — правда важнее охвата

## 🎯 Стратегии победы

### Путь Баланса ⚖️
Держи все метрики в зелёной зоне (4-7). На этапе 3 выравнивай слабые показатели.  
**Цель**: Охват ≥6, Душа ≥6, Деньги ≥4, Энергия ≥4

### Путь Души 🫀
Выбирай честность. Храни дружбу с Сашей. Дай интервью Павлу.  
**Финал**: Тишина или Документ

### Путь Охвата 📡
Принимай коллабы. Адаптируйся под алгоритм. Союз с ViralKing.  
**Финал**: Слияние или Вечная лента

## 🎮 Управление

Каждая карточка — предложение. Отвечай согласием или отказом:

### Desktop
- **← стрелка влево** — отказаться (красное ✕ Нет)
- **→ стрелка вправо** — согласиться (зелёное ✓ Да)
- **Click** на кнопки «✕ Нет» / «Да ✓»
- **Hover** на кнопки — предпросмотр эффекта на метриках («+» / «−»)

### Mobile
- **Swipe left** ← — отказаться (красное ✕ Нет)
- **Swipe right** → — согласиться (зелёное ✓ Да)
- **Tap** на кнопки «✕ Нет» / «Да ✓»
- Страница не прокручивается во время свайпа; штампы НЕТ / ДА появляются на карточке по мере наклона

> Правило всегда одно: **красное ✕ = несогласие (влево)**, **зелёное ✓ = согласие (вправо)**.
> Если персонаж предлагает сомнительную сделку — вопрос сформулирован как
> «откажешь?», так что зелёным подтверждается именно твой ответ на вопрос карты.

## 🏗️ Запуск проекта

```bash

npm install

# Запуск dev-сервера
npm run dev

# Сборка (пишет готовую игру в docs/index.html)
npm run build
```

## 🌍 GitHub Pages и запуск без сервера

Игра собирается в **один самодостаточный файл** — `docs/index.html`
(все стили и скрипты инлайн, внешних запросов нет):

- **Прямо сейчас:** скачайте репозиторий и откройте `docs/index.html`
  двойным кликом — игра работает без какого-либо сервера.
- **GitHub Pages:**
  1. Зайдите в **Settings → Pages** репозитория
  2. В «Build and deployment» выберите **Deploy from a branch**
  3. Branch: **main**, folder: **/docs** → **Save**
  4. Игра будет доступна по адресу `https://SodoMita.github.io/feed/`
- **Обновить собранный файл:** `npm run build` (перезаписывает `docs/index.html`),
  закоммитить и запушить.
