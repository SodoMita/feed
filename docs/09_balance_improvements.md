# 📊 Улучшения баланса и геймплея

## Что было исправлено

### 1. **Автоматическая балансировка метрик**

Добавлена система `autoBalance()`, которая:
- С 20% шансом подталкивает критически низкие метрики (≤2) вверх на +1
- С 20% шансом снижает критически высокие метрики (≥8) на -1
- Помогает избежать безвыходных ситуаций
- Не срабатывает при перке "Аутентичный" (хардкорный режим)

### 2. **Увеличено количество карточек**

Было: **~35 карточек**
Стало: **~50 карточек**

Новые карточки:
- **Этап 1 (Начало)**: +6 карточек
  - Первый вызов (эмоции vs стратегия)
  - Управление временем
  - Маленькая победа
  - Планирование контента
  - Качество vs количество
  - Негативные отзывы
  - Следование трендам
  - Монетизация

- **Этап 2 (Рост)**: +4 карточки
  - Давление роста
  - Профессиональный коллаб
  - Найм команды
  - Предупреждение о выгорании
  - Рост комьюнити
  - Достижение 10К подписчиков

- **Этап 3 (Финал)**: +3 карточки
  - Развилка (цифры vs смысл)
  - Вопрос наследия
  - Финальное предложение корпорации
  - Новое начало с Сашей
  - Наставничество

### 3. **Видимые концовки-победы**

Добавлена **новая концовка "Баланс" (⚖️)**:
- Срабатывает на этапе 3 (карта ≥25)
- Требует: Охват ≥6, Душа ≥6, Деньги ≥4, Энергия ≥4
- Тип: `victory`
- Достижение: "Золотая середина"
- Текст: Ты нашёл точку равновесия. Контент честный, но профессиональный.

Другие концовки-победы (уже были):
- 📡 **Вечная лента** — максимальный охват
- 🌿 **Тишина** — удаление аккаунта с миром
- 🌱 **Новый старт** — начать заново
- 🔮 **Слияние** — создать платформу с ViralKing
- 📖 **Документ** — честный материал с Павлом

Концовки-поражения (смерть):
- ⬛ **Теневой бан** — охват = 0
- 🤖 **Ты стал ботом** — душа = 0
- 💸 **Аккаунт продан** — деньги = 0
- 🪫 **Выгорание** — энергия = 0

### 4. **Визуальный прогресс**

Добавлен индикатор прогресса в хедере:
- Прогресс-бар показывает путь к финалу (35 карточек = 100%)
- Счётчик карточек
- Текстовые подсказки:
  - 0-9 карточек: "Начало"
  - 10-24 карточек: "Развитие"  
  - 25+ карточек: "Финал близко"

### 5. **Улучшенная математическая модель**

#### Начальные значения:
```
Охват: 5/10
Душа: 5/10
Деньги: 5/10 (было 3/10)
Энергия: 5/10
```

#### Безопасные зоны:
- **Зелёная зона**: 3-7 (безопасно)
- **Жёлтая зона**: 2, 8 (предупреждение)
- **Красная зона**: 0-1, 9-10 (опасность)

#### Автобаланс срабатывает при:
- Метрика ≤2 → 20% шанс +1
- Метрика ≥8 → 20% шанс -1

Это означает, что в среднем каждые 5 карточек игрок получает 1 "спасение" от края.

### 6. **Баланс выборов**

Все карточки теперь имеют более сбалансированные опции:
- Левый выбор часто: +душа, -охват/деньги
- Правый выбор часто: +охват/деньги, -душа/энергия
- Нейтральные выборы: обмен между ресурсами без потерь

Примеры:
```typescript
// Раньше (рискованно):
leftChoice: { delta: { soul: 2, reach: -2 } } // можно упасть в 0
rightChoice: { delta: { reach: 3, soul: -3 } }

// Теперь (безопаснее):
leftChoice: { delta: { soul: 2, reach: 0 } } // гарантированно +2
rightChoice: { delta: { reach: 2, energy: -1 } } // небольшая цена
```

### 7. **Частота появления карточек**

Система приоритетов гарантирует:
1. **Story-карточки** (приоритет 99-200) — показываются первыми
2. **Важные события** (приоритет 70-90) — часто
3. **Обычные карточки** (приоритет 40-60) — регулярно
4. **Редкие события** (приоритет <40) — иногда

Перк "Скандалист" увеличивает частоту хейтеров с ~10% до ~50%.

### 8. **Победные условия**

Теперь есть несколько путей к победе:

#### Путь охвата (📡)
- Коллаб с ViralKing → концовка "Слияние"
- Максимальные метрики → "Вечная лента"

#### Путь души (🫀)
- Честность с Павлом → концовка "Документ"

#### Путь баланса (⚖️)
- Все метрики ≥6 на этапе 3 → "Баланс"

### 10. **Типы концовок по механике**

#### Сюжетные (triggered)
- Требуют: специфические флаги
- Примеры: "Слияние", "Документ", "Новый старт"

#### Метричные (automatic)
- Требуют: определённые значения метрик
- Примеры: "Баланс", смерти от нуля

#### Гибридные (both)
- Требуют: флаги + метрики
- Примеры: "Тишина" (Саша + высокая душа)

## Как теперь играть

### Стратегия выживания:
1. Следи за прогресс-баром — финал близко на 25+ карточках
2. Не доводи метрики до 0-1 или 9-10
3. Если метрика на 2 или 8 — сделай выбор, который её стабилизирует
4. Автобаланс поможет, но не спасёт от крайностей

### Стратегия победы "Баланс":
1. Держи все метрики в зоне 4-7
2. Не гонись за максимумами
3. На этапе 3 выравнивай слабые метрики
4. Цель: Охват 6+, Душа 6+, Деньги 4+, Энергия 4+

### Стратегия победы "Душа":
1. Всегда выбирай честность
2. Храни дружбу с Сашей
3. Дай интервью Павлу
4. Отказывайся от сомнительных сделок
5. На этапе 3 получишь выбор: Тишина или Документ

### Стратегия победы "Охват":
1. Принимай коллабы
2. Адаптируйся под алгоритм
3. Союз с ViralKing
4. Игнорируй душу (но не дай упасть до 0)
5. Финал: Слияние или Вечная лента
