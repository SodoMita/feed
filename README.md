# 📱 FEED — Игра про инфлюенсера

> *Reigns-like игра про путь создателя контента в социальных сетях*

## 🎮 О игре

Ты — новый аккаунт. Серый круг на аватарке. Пустая биография. Впереди — вся лента.

Свайпай карточки влево ← и вправо → (или используй стрелки на клавиатуре).  
Каждый выбор меняет твои метрики. Каждая метрика на нуле — конец.  
Но и максимум — не всегда хорошо.

## 📊 Метрики

- **📡 Охват** — тебя видят
- **🫀 Душа** — ты настоящий
- **💰 Монета** — ты в деньгах
- **⚡ Топливо** — у тебя силы

Держи баланс. Или выбери путь.

## ✨ Особенности

### Глубокая механика
- **50+ уникальных карточек** с разными персонажами
- **3 этапа развития**: Старт → Рост → Вершина
- **8 перков** (позитивных и негативных)
- **Флаги и триггеры** для ветвления сюжета
- **Автобалансировка** для комфортной игры

### Разные концовки

#### 🏆 Победы (6 концовок):
- **⚖️ Баланс** — найти золотую середину
- **📡 Вечная лента** — стать везде
- **🌿 Тишина** — уйти с миром
- **🌱 Новый старт** — начать заново
- **🔮 Слияние** — создать платформу
- **📖 Документ** — правда важнее охвата

#### 💀 Поражения (4 концовки):
- **⬛ Теневой бан** — охват упал до нуля
- **🤖 Ты стал ботом** — душа кончилась
- **💸 Аккаунт продан** — деньги кончились
- **🪫 Выгорание** — энергия кончилась

### Живые персонажи

Каждый персонаж комментирует твой путь в **Журнале**:

- **🌱 Саша** — твой первый подписчик, хранитель искренности
- **🤖 Алгоритм** — система, которая тебя изучает
- **💼 Алина** — агент с прошлым
- **😤 Хейтер** — который может стать другом
- **📰 Павел** — журналист в поиске правды
- **🔥 ViralKing** — король вирального контента
- **🪞 @Mirror** — твоё прошлое Я

## 🎯 Стратегии победы

### Путь Баланса ⚖️
Держи все метрики в зелёной зоне (4-7). На этапе 3 выравнивай слабые показатели.  
**Цель**: Охват ≥6, Душа ≥6, Деньги ≥4, Энергия ≥4

### Путь Души 🫀
Выбирай честность. Храни дружбу с Сашей. Дай интервью Павлу.  
**Финал**: Тишина или Документ

### Путь Охвата 📡
Принимай коллабы. Адаптируйся под алгоритм. Союз с ViralKing.  
**Финал**: Слияние или Вечная лента

## 🎮 Управление

### Desktop
- **← стрелка влево** — левый выбор
- **→ стрелка вправо** — правый выбор
- **Click** на кнопки выбора
- **Hover** на кнопки — предпросмотр эффекта

### Mobile
- **Swipe left** ← — левый выбор
- **Swipe right** → — правый выбор
- **Tap** на кнопки выбора
